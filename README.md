# Wendong_2025_Spatiotemporal_InSAR_dataset_prediction

This repository is now a minimal CAGEO-only reproduction package for:

`A Reproducible Sparse-to-Dense InSAR Computing Pipeline with Hybrid CNN-LSTM Forecasting`

Only the files required to rerun the CAGEO training and validation pipeline are versioned.

Repository scope:

- `experiments/` contains the executable CAGEO code, environment files, dataset placement note, and reproduction instructions
- historical manuscript figures, legacy guidance files, and previously generated result artifacts are intentionally not tracked
- raw EGMS data are not bundled here; see `experiments/datasets/README.md`
