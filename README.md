# Wendong_2025_Spatiotemporal_InSAR_dataset_prediction

This repository hosts the curated CAGEO experiment package for the manuscript:

`A Reproducible Sparse-to-Dense InSAR Computing Pipeline with Hybrid CNN-LSTM Forecasting`

The paper-aligned code, configuration snapshots, saved split definitions, summary results, reproducibility audits, and figure/table assets are organized under `experiments/`.

Repository scope:

- `experiments/` contains the current standalone experiment bundle used for the manuscript line
- `LICENSE` is already present in this public repository
- raw EGMS data are not bundled here; see `experiments/datasets/README.md` for the expected CSV filename and acquisition note
